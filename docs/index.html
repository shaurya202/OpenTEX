The Spectral Theorem for Symmetric Matrices

Theorem (Real Spectral Decomposition)
Every real symmetric matrix A = AT in ℝn × n is orthogonally diagonalizable:
A = Q Λ QT,    QTQ = I
All eigenvalues are real and eigenvectors from distinct eigenspaces are orthogonal.
  • Real eigenvalues guarantee stability in quadratic forms.
  • Exports as compilable LaTeX Beamer code or printable PDF slides.
